# ASR confidence evaluation follow-up

The native capture/reply evaluators use explicitly synthetic confidence 0.95. The existing Moonshine v0.1.5 word-alignment source assigns constant 1.0; adding its optional attention decoder does not by itself establish a confidence signal. This task implements the independent offline evaluation prerequisite, without changing that runtime, ordinary recognition policy or production readiness.

`packages/dataset-evaluation/confidence.py` accepts bounded, closed-schema score/label records. It computes Brier score, ten-bin equal-width ECE, tie-aware correctness AUROC and fixed-grid coverage/error risk. The 0.85 row describes the current numeric policy cutoff; no threshold is fitted, selected or authorized. Single-class labels have unavailable AUROC; zero accepted cases have undefined risk. Placeholder/synthetic scores and constant signals are explicitly flagged unusable or uninformative. Even varied declared model scores only yield diagnostic output, never acceptance.

Optional complete ASR benchmark binding reuses the existing source/report validator. Canonical manifest/report digests and adapter model/binary pins must agree. All cases must be ASR test cases, opaque case digests must exactly cover the source, and exact-match labels must match zero word/character errors. Synthetic benchmark sources cannot be relabelled as model probabilities. The checks establish consistency, not authenticity of scores, annotation truth, native execution or exclusion from training data.

Exports are deterministic aggregate JSON and local HTML, with no case IDs, per-case scores/labels, transcript, speaker identity, audio or paths. Existing output directories are never overwritten. Physical gates and native calibration remain NOT_RUN, production NOT_ENABLED, threshold authorization NOT_GRANTED and quality acceptance NOT_ASSESSED.

Sixteen tests cover hand-computed metrics, 50 seeded pairwise AUROC comparisons with ties, order invariance, bin endpoints, all-ones/placeholder signals, one-class and zero-coverage cases, malformed/nonfinite/duplicate/oversize inputs, source/model/report/label changes, missing/extra scores, known training/non-ASR source denial, CLI binding and privacy/no-overwrite export. Tests pass with and without Python optimization. Existing synthetic workflow discovery includes them automatically; no CI gate is weakened.

Normal regression checks: 325 Swift tests and normal simulator build/install/three fresh launches; 380 Android tests plus lintDebug, assembleDebug and compileReleaseKotlin. The existing complete synthetic workflow blocks also pass. No model, runtime, package, microphone, physical phone, network observer, service, account or new license acceptance was needed. Real native confidence/calibration is still blocked and S08/release remains HOLD; persistent memory remains disabled.
