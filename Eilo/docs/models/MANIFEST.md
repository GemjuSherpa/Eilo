# Native model pack contract

Schema 1 is bounded UTF-8 JSON (64 KiB maximum). It declares schema, packId, positive revision, exact runtimeRevision, minimum Android/iOS versions and 1–16 artifacts. Each artifact declares id, safe single-component filename, role, HTTPS URL without query/credentials/fragment, SHA-256, byte size, SPDX license and SHA-256 of license evidence. No escaped strings, unknown fields, duplicate keys, negative/fractional numbers or trailing commas. Generic ASCII metadata avoids parser differences. Manifests are signed over the exact bytes; JSON reserialization is never used for signature verification.

Runtime revisions must match exactly. Paths cannot traverse directories. Artifact IDs/filenames are unique, files are bounded to 8 GB and total pack size to 12 GB. License declarations are not legal clearance; complete source/license inventory and review remain necessary before pack inclusion.

VC-PACK-03: Kotlin compiler + 29 JUnit tests and Swift compiler + 29 XCTest tests passed locally, including schema rejection cases. Kotlin uses Android's platform org.json; the pinned JSON-java 20250517 test-only dependency supplies executable JVM parser tests. Physical Android parser/crypto behavior remains to be verified.

VC-PACK-04: ES256 (ECDSA P-256/SHA-256), DER signature and DER SPKI public key; native platform JCA/CryptoKit implementations only. Exact raw payload bytes are verified before parsing. Trust lookup is configured locally, never fetched from the manifest. Empty trust fails closed. Local test keys are generated in memory and are not shipping keys. Kotlin compiler/JUnit30 and Swift compiler/XCTest30 pass for valid signatures, tampering, unknown key, unsupported algorithm and empty production trust. Physical Android JCA remains unverified.

VC-PACK-05: Native streaming downloader accepts only generic signed asset metadata and bounded Range/If-Range validators. It uses an independent allowlist, default TLS certificate verification, no cookies/authentication/cache, no automatic redirects/retries and fixed generic User-Agent. Kotlin isolates an OkHttp client from React Native interceptors; Swift uses an ephemeral URLSession. Redirects are manually checked before each request (maximum four); foreign/non-HTTPS/unconfigured origins are blocked. Writes remain staging-only and length/encoding/cancellation checks fail closed. Blocking installer work belongs on an installer worker, not UI/audio threads. Compiler/JUnit33 and compiler/XCTest33 pass against synthetic server adapters; real CDN and packet capture checks are not release evidence yet.

VC-PACK-06: Stream SHA-256 over exact declared bytes with bounded memory, cancellation, regular-file checks and no-follow final symlink handling. File metadata changes during verification reject the proof. Truncated, oversized, bit-flipped and symlink fixtures cannot obtain a verified artifact. Compiler/JUnit35 and compiler/XCTest35 pass. Generic staging data may persist between interrupted setup attempts; no personal data is accepted.

VC-PACK-07: Interrupted downloads retain only generic partial bytes and a bounded checkpoint binding signed-manifest digest, artifact index and strong ETag. Resume sends Range/If-Range; changed ETag or a full response restarts cleanly. Missing/invalid checkpoints restart, never trust partial data. Complete bytes are always rehashed. Compiler/JUnit37 and compiler/XCTest37 pass for injected interruption, resume, changed ETag and malformed checkpoint. Real process-kill/device recovery remains unverified.

VC-PACK-08: Activation reverifies signature, configured license evidence and every file before/after copying into an immutable version directory. One atomic, synced pointer commits the complete pack; failed work before that point leaves the previous pointer unchanged. Crash after commit exposes the complete new version. Startup rechecks stored signatures/hashes; tampering fails closed. Revision downgrade and same-revision replacement are rejected. Shared process locks serialize transactions across store instances. Compiler/JUnit39 and compiler/XCTest39 pass for failure injection at copy/verification/pointer boundaries, restart, stale proof, corrupted active file, empty trust and missing license approval. Real abrupt process death/power-loss/filesystem/device tests remain unverified; old versions are preserved and generic orphan cleanup is best effort, not personal secure erasure.

VC-PACK-09: Native Start gates readiness before permission, after permission completion and after capture adapter return; stale output checks readiness again. Missing/incompatible/corrupt/incomplete/unsupported/offline-voice states are allowlisted metadata reasons in Kotlin/Swift and the TypeScript event validator. Readiness refresh validates signatures/files on the installer worker; status is constant-time and invalidated by activation epochs. Complete generic LLM/ASR/wake/VAD assets and supported native configuration/offline voice are required. No automatic Start follows installation. Compiler/JUnit43, compiler/XCTest43, actual iOS SDK typecheck, lint, strict TypeScript and JavaScript34 pass. Real model runtime integration, phone feasibility and offline voice checks are later gates. Android root is noBackupFilesDir; explicit iOS store creation sets backup exclusion/protection. Physical backup behavior is unverified. Android Internet permission now supports the isolated model downloader; there is no configured production download or cloud inference path.
