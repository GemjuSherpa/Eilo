# S06 / VC-VOICE-03 — iOS offline speech adapter

AVSpeechSynthesizer now has a native exact-voice adapter with bounded current-turn requests, asynchronous main-thread SDK work, epoch/generation checks, cancellation and metadata-only completion events. No fallback language, file synthesis, personal-voice permission or production caller is added. Unknown offline capability requires an explicit exact voice/OS-build evidence record; the normal app has none. SDK mutable state is confined to main; delegate callbacks are marshaled there before access. The SDK's Sendable delegate requirement is documented with this manual isolation, without suppressing compiler diagnostics.

Strict Swift source compilation and four focused queue/voice/bounds/cancellation tests PASS. A standalone iPhone 18 Pro/iOS27 simulator probe verifies the default unknown-offline gate and actual SDK speech completion with an explicitly synthetic voice/OS record. SDK-start timing is recorded as a callback measurement, not first audible audio or physical latency. [Recorded evidence](../../packages/offline-speech/tests/ios-results.json). The normal app build required importing AVFoundation before the generated Swift bridge header; this compatibility fix and scoped Xcode references preserve personal signing/plist/S02 edits. Final Debug build and three fresh ten-second launches PASS before commit.

Reproduce from `Eilo/packages/native-test-seam`: `swift build -Xswiftc -warnings-as-errors` and `swift test --filter IOSOfflineSpeechTests`. From `Eilo`: `python3 packages/offline-speech/check_ios.py --udid <booted-simulator-UUID>`. No downloads or microphone are used. The probe explicitly selects the simulator SDK; the earlier incompatible-sysroot linker warning is resolved. Apple [voice selection](https://developer.apple.com/documentation/avfaudio/avspeechsynthesisvoice) and [speech synthesis](https://developer.apple.com/documentation/avfaudio/avspeechsynthesizer) provide platform callbacks, not a network-independent guarantee or proof the user heard speech.

Native owned references clear on cancellation; immutable/framework copies are not certified erased.
