# Isolated SDK score propagation experiment

Instrumentation applies only to a verified copy of the approved Moonshine v0.1.5 source.
The immutable source cache and ordinary app runtime are unchanged. This package is an
invocation-only Android emulator probe, with no audio hardware, text output or policy use.

Initial execution exposed a failing late-divergence fixture assumption; initial-failure.json
retains that experimental failure. Integration and final evidence are still in progress.
All physical gates remain open; probabilities are uncalibrated and do not authorize production.
